# 宇宙的奧秘與人生的意義 · 星海旅人

原生 HTML / CSS / JavaScript 本機手機跑酷，無建置流程、套件安裝或外部素材依賴。

## 本地啟動

直接開啟 index.html，或在專案資料夾執行 `python3 -m http.server 8080`，瀏覽 `http://localhost:8080`。同 Wi-Fi 的手機可使用電腦區網 IP 加上 :8080。

## GitHub Pages

公開遊戲網址：https://sunsyuewei.github.io/cosmic-journey/

儲存庫：https://github.com/SunSyueWei/cosmic-journey

Pages 使用 main 分支根目錄，自動發布每次推送；`.nojekyll` 表示直接提供靜態檔案。更新後如有快取問題，同步更新 index.html 的資源版本參數。

GitHub 只儲存程式碼，Pages 只提供靜態網頁；它不會保存玩家分數。現在共用排行榜已接上 Supabase：開始畫面詢問暱稱並提醒勿透露個資；「是，顯示於排行榜」預設勾選，但保留過往取消的選擇。玩家按啟程確認並保持勾選，首次加入通過 Turnstile 驗證後，該局才會以匿名身分上傳暱稱、分數、距離與卡片數；單純查看排行榜不建立帳號。未勾選仍可完整遊玩，紀錄只留在裝置的 localStorage。暱稱請勿使用真名、電話、學校或班級。

## 共用排行榜與安全設定

- `js/cloud-config.js` 只包含 Supabase Project URL 與 `sb_publishable_` Publishable Key。這類前端金鑰本來就會被玩家看見；絕不能放入 `service_role`、`sb_secret_`、資料庫密碼或其他私密金鑰。
- Supabase 的 `supabase/setup.sql` 需在 SQL Editor 執行，並在 Authentication → Sign In / Providers 開啟 Anonymous Sign-Ins。正式活動若要開啟 Supabase CAPTCHA/Turnstile，需同時把 token 介接到 `cloud.js`；只在 Dashboard 單方面強制開啟會讓登入失敗。
- 資料表啟用 RLS、撤銷 anon/authenticated 直接讀寫；排行榜函式只回傳公開欄位，其餘三個受限函式才處理開局、提交與刪除自己的成績。伺服器依距離、時間與光門前後卡片數重新計分；前端不能直接指定分數。
- 遊戲頁的「刪除我的雲端成績」只刪除目前瀏覽器匿名身分的遊戲紀錄，不會刪除 Supabase 驗證技術日誌。清除瀏覽器資料後會失去原匿名身分；遺失身分時請向主辦人提出刪除要求。
- GitHub Pages 已使用 HTTPS；頁面另設 CSP、`no-referrer`、只允許連到本專案 Supabase 網域。GitHub Pages 無法自訂 `frame-ancestors` 等 HTTP 安全標頭，如需防嵌入可改用 Cloudflare Pages／自有網域加標頭。
- Supabase Free 專案可能因長時間無活動暫停，活動前請登入 Dashboard 確認專案狀態、RLS 與 Anonymous Sign-Ins。排行榜只回傳公開暱稱、分數、距離及名次，不回傳 user ID、token 或場次 ID。

## 操作與規則

進入頁面後預設開啟聲音，點「啟程」時播放音樂；同一次頁面內手動靜音後，重新開始仍保持靜音。聲音按鈕在遊戲右上角。手機橫向使用接近整個可視螢幕，Canvas 依容器比例重新計算世界寬度，避免拉伸；排行榜及隱私設定可往下捲動使用。相關版面規則在 `layout.css`。

點畫面／空白鍵／方向上鍵跳躍，落地後才能再跳。晶岩、裂隙和隕石碰撞即結算。P、Escape 或暫停按鈕可暫停；切換視窗或 App 自動暫停。觸控手勢限制只作用在遊戲 Canvas，其他介面保留縮放。

每公尺 1 分、每张邀請卡 100 分。1,000 m 穿過聚會光門，加 2,000 分；往後新增距離與邀請卡分數 ×1.5，每 500 m 額外 500 分。抵達後仍持續遊玩。

## 隨機障礙與無上限速度

- 起步 210 px/s；光門前每秒加 1.8 px/s，光門後每秒加 7.2 px/s。**沒有航行速度上限**。
- 障礙使用零散單顆、短連發及較長空檔三種隨機節奏，每次還有時間差與種類變化。隨遊戲時間增加，連發機率提高、暖身空檔縮短。
- 最短間距以完整跳躍時間（約 0.72 秒）、落地緩衝、障礙寬度與加速度估算，不生成必須尚未落地就再次跳躍的排列。
- 速度不封頂，因此後期可見障礙的反應時間會持續縮短，挑戰最終會非常困難。碰撞採水平掃掠檢查，避免高速物件跨過角色而未判定碰撞。
- 背景音樂使用提供的《宇宙奧祕》M4A（AAC），存於 `assets/audio/cosmic-mystery.m4a`，循環播放。每跨入一個 1,000 m 星球場景加速 0.08 倍（水星 1.00、金星 1.08、地球 1.16），最高 1.8 倍，盡量保留音高；此音樂保護不限制航行速度。暫停／收藏卡畫面暫停播放，繼續時接續原位置，重新開始從歌曲開頭播放。

| 1,000 m | 金星探索者；同時穿過聚會光門 |
| 2,000 m | 地球探索者 |
| 3,000 m | 火星探索者 |
| 4,000 m | 木星探索者 |
| 5,000 m | 土星探索者 |
| 6,000 m | 天王星探索者 |
| 7,000 m | 海王星探索者 |
| 8,000 m | 冥王星探索者 |
| 9,000 m | 九星旅人：完整探索紀念卡 |

九張行星卡各有配色、行星圖案、地貌名稱與文案；另有一張完整旅程卡。這是含冥王星的幻想旅程，氣體行星跑道為架空場景。

抵達新行星時只在遊戲上方淡入淡出約 3 秒的收藏提示，遊戲、障礙與音樂持續進行。結束時顯示本局最高成就卡與最終成績，關閉後可查看結算；收藏冊可切換所有已取得卡片，下載 900 × 1,100 PNG 或自行截圖分享。第一輪每張卡每局發放一次，9,000 m 後星球循環，速度與分數繼續增加。重玩可重新取得卡片，本機保存每種卡的最新快照；不會自動傳送圖片給任何人。

音樂只在切換星球時設定一次播放倍率，同一星球內固定，不重播、不重設歌曲進度；九星循環後不降速，重新開始則回到 1 倍。可在 js/config.js 調整 musicRateStep 與 musicMaxRate。此改動不影響持續增加的航行速度。

舊版 4,500 m 成就會保留並標示「舊版紀念」，不冒充新版 9,000 m 完成紀錄。

## 結構與參數

- index.html、styles.css：遊戲介面、響應式布局與收藏冊。
- js/config.js：物理、兩階段加速度、星球與光門距離、計分參數。
- js/game.js：120 Hz 固定步長、畫面補間、碰撞、成就發放。
- js/obstacles.js：隨機障礙節奏及安全間距。
- js/space.js：九星球、快取星空、連續世界座標地形與 28 m 漸變轉場。
- js/achievement.js：行星卡與完整旅程卡繪製、PNG 下載。
- js/audio.js：M4A 循環播放、速度連動、合成音效；替換歌曲可更新 `assets/audio/cosmic-mystery.m4a`。
- js/storage.js：localStorage、隱私同意與可替換的 async 排行榜介面。
- js/cloud-config.js、js/cloud.js：Supabase REST/匿名登入配接層；可替換成其他後端而不改遊戲邏輯。
- SECURITY.md：發布前檢查、私密金鑰事故處理與玩家資料請求措施。

畫面使用固定星點與世界座標地形，避免回捲時突然換圖；星空與行星紋理快取，HUD 每秒更新 10 次。更換角色可修改 astronaut()，更換背景修改 SpaceScene。改變跳躍物理時需同時確認障礙間距。

## 資料與排行榜

共用模式的今日排行以台灣日期計算，本次活動依 `eventId` 篩選；每個匿名玩家只顯示最佳成績，同分以距離及提交時間排序。未連線或未啟用時，會回到本機示範排行。保存最近 500 局、個人最高分、暱稱、音量、參加選擇與收藏卡；清除網站資料會移除本機紀錄。localStorage 不可用時退回記憶體。

若未來改用 Supabase Edge Function、Firebase Callable Function 或其他後端，只需替換 `js/cloud.js` 的 `begin/submit/list/deleteMine`，保留 `RunStore` 介面；伺服器端必須繼續驗證成績、RLS/規則及刪除權限。這是基本合理性驗證，不是完整伺服器重播防作弊；不要將未驗證的客戶端分數直接寫入公開表。file:// 儲存行為依瀏覽器而異，測試建議使用 HTTP。

## 驗證

### 流暢度調整（2026-09-17）

- 地形依世界座標快取每組 128 個高度樣本，最多 64 組；平常只取目前星球，28 m 轉場才混合兩組。不再逐幀建立地形座標陣列。星點參數預先計算，穩定場景合併快取星空與行星。
- 遊戲 Canvas 使用不透明繪圖，初始像素倍率最多 1.5，總像素上限約 150 萬；連續 2 秒平均低於 45 FPS 時逐步降低倍率，最低 0.75，重新載入恢復。只調整遊戲畫布清晰度，不改速度、物理、計分或成就卡匯出尺寸。
- 暫停／待機／結算不再持續重繪。相同尺寸的 resize 不重設畫布。
- 250 ms 內的掉幀完整補算 120 Hz 物理；超過 250 ms 明確暫停並提示，按繼續恢復，不做危險的大幅追趕。這是保護性暫停，並非消除所有裝置卡頓。
- 下方重複設定區塊已移除，刪除自己雲端成績及資料使用說明收進排行榜的「資料與隱私」。開始前仍可選擇不公開。
- `tests/smoke.cjs` 額外驗證不規則幀間隔、長停頓保護、快取地形一致性與容量上限。Node 測試不代表實機 Safari GPU／音訊效能量測。

執行 `node tests/smoke.cjs`、`node tests/audio.cjs`、`node tests/cloud.cjs` 與 `node tests/privacy.cjs`。涵蓋開始、跳躍、三種碰撞、到站、無上限加速、高速掃掠、障礙間距與隨機模式、每千公尺解鎖、九張卡持久化、9,000 m 成就、安全繼續、PNG 匯出程式路徑、音樂調速、暫停與靜音、不同更新頻率的行進一致性、匿名登入並發、伺服器計分 payload、雲端錯誤，以及「未同意不上傳」和刪除委派。

`?test=1` 使用獨立測試儲存，頁面底部提供各星球卡與完整旅程測試按鈕；不會污染正常遊玩的成績及收藏。實際音訊、手機手感仍可在活動裝置上試玩調整。
