# 宇宙的奧秘與人生的意義 · 星海旅人

原生 HTML / CSS / JavaScript 本機手機跑酷，無建置流程、套件安裝或外部素材依賴。

## 本地啟動

直接開啟 index.html，或在專案資料夾執行 `python3 -m http.server 8080`，瀏覽 `http://localhost:8080`。同 Wi-Fi 的手機可使用電腦區網 IP 加上 :8080。

## GitHub Pages

公開遊戲網址：https://sunsyuewei.github.io/cosmic-journey/

儲存庫：https://github.com/SunSyueWei/cosmic-journey

Pages 使用 main 分支根目錄，自動發布每次推送；`.nojekyll` 表示直接提供靜態檔案。更新後如有快取問題，同步更新 index.html 的資源版本參數。

**排行榜目前仍為本機紀錄，不是共用排行榜。** GitHub 儲存程式碼；Pages 提供網頁；分數、暱稱、最高分和收藏卡存在每位玩家瀏覽器的 localStorage，不會傳送到 GitHub。不同裝置、瀏覽器、網址來源（例如 localhost 與正式 Pages）各有獨立紀錄，清除網站資料會刪除紀錄。要跨手機競賽，需要另外接上後端資料庫及成績驗證服務。

## 操作與規則

點畫面／空白鍵／方向上鍵跳躍，落地後才能再跳。晶岩、裂隙和隕石碰撞即結算。P、Escape 或暫停按鈕可暫停；切換視窗或 App 自動暫停。觸控手勢限制只作用在遊戲 Canvas，其他介面保留縮放。

每公尺 1 分、每张邀請卡 100 分。1,000 m 穿過聚會光門，加 2,000 分；往後新增距離與邀請卡分數 ×1.5，每 500 m 額外 500 分。抵達後仍持續遊玩。

## 隨機障礙與無上限速度

- 起步 210 px/s；光門前每秒加 1.8 px/s，光門後每秒加 7.2 px/s。**沒有航行速度上限**。
- 障礙使用零散單顆、短連發及較長空檔三種隨機節奏，每次還有時間差與種類變化。隨遊戲時間增加，連發機率提高、暖身空檔縮短。
- 最短間距以完整跳躍時間（約 0.72 秒）、落地緩衝、障礙寬度與加速度估算，不生成必須尚未落地就再次跳躍的排列。
- 速度不封頂，因此後期可見障礙的反應時間會持續縮短，挑戰最終會非常困難。碰撞採水平掃掠檢查，避免高速物件跨過角色而未判定碰撞。
- 音樂跟隨速度從 108 BPM 持續升高，漸近 240 BPM 以保持可聽性；此音樂節奏保護不限制航行速度。暫停／收藏卡畫面停止背景旋律，重新開始回到起步節奏。

九張行星卡各有配色、行星圖案、地貌名稱與文案；另有一張完整旅程卡。這是含冥王星的幻想旅程，氣體行星跑道為架空場景。

抵達新行星時自動暫停並開啟卡片，可下載 900 × 1,100 PNG 或自行截圖分享。收藏冊可以切換所有已取得卡片；未解鎖的卡片不會出現。繼續後保留速度與分數，清空眼前障礙、提供 2 秒安全路段。第一輪每張卡每局發放一次，9,000 m 後星球循環，速度與分數繼續增加。重玩可重新取得卡片，本機保存每種卡的最新快照；不會自動傳送圖片给任何人。

舊版 4,500 m 成就會保留並標示「舊版紀念」，不冒充新版 9,000 m 完成紀錄。

## 結構與參數

- index.html、styles.css：遊戲介面、響應式布局與收藏冊。
- js/config.js：物理、兩階段加速度、星球與光門距離、計分參數。
- js/game.js：120 Hz 固定步長、畫面補間、碰撞、成就發放。
- js/obstacles.js：隨機障礙節奏及安全間距。
- js/space.js：九星球、快取星空、連續世界座標地形與 28 m 漸變轉場。
- js/achievement.js：行星卡與完整旅程卡繪製、PNG 下載。
- js/audio.js：音訊時鐘排程、速度連動節拍、音效。
- js/storage.js：localStorage 與未來可替換的 async 排行榜介面。

畫面使用固定星點與世界座標地形，避免回捲時突然換圖；星空與行星紋理快取，HUD 每秒更新 10 次。更換角色可修改 astronaut()，更換背景修改 SpaceScene。改變跳躍物理時需同時確認障礙間距。

## 資料與排行榜

排行榜是本機展示版，三位示範選手皆有標記。今日排行依裝置日期計算，本次活動依 eventId 篩選；每位裝置選手顯示最高分，同分以距離及時間排序。保存最近 500 局、個人最高分、暱稱、音量與收藏卡；清除網站資料會移除紀錄。localStorage 不可用時退回記憶體。

若未來串接後端，替換 RunStore.submit(result)、list(period)，使用匿名身分及伺服器成績驗證，移除示範資料。現階段不支援跨手機競賽，也不提供防作弊保證。file:// 儲存行為依瀏覽器而異，測試建議使用 HTTP。

## 驗證

執行 `node tests/smoke.cjs` 與 `node tests/audio.cjs`。涵蓋開始、跳躍、三種碰撞、到站、無上限加速、高速掃掠、障礙間距與隨機模式、每千公尺解鎖、九張卡持久化、9,000 m 成就、安全繼續、PNG 匯出程式路徑、音樂調速、暫停與靜音，以及不同更新頻率的行進一致性。

`?test=1` 使用獨立測試儲存，頁面底部提供各星球卡與完整旅程測試按鈕；不會污染正常遊玩的成績及收藏。實際音訊、手機手感仍可在活動裝置上試玩調整。
